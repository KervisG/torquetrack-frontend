# TorqueTrack Diesel — frontend

SPA de la tienda de repuestos diesel TorqueTrack (Estados Unidos): tienda, portal de cliente y panel de administración, con Vite + React + TypeScript. Consume la API del repo `torquetrack-backend` (Django + DRF); nunca importa su código. El `README.md` explica cómo levantarlo.

## Idioma

Cargar `skills/language-convention/SKILL.md` antes de escribir código. Identificadores, componentes, rutas y todo lo que ve el usuario van en inglés. Comentarios van en español. La documentación del repositorio se escribe en español con nombres de archivo en inglés.

## Skills

- `skills/language-convention/SKILL.md` — producto en inglés, comentarios y documentación en español.
- `skills/frontend-feature-structure/SKILL.md` — estructura de features y reglas de datos de `src/`.

## Entrega

Commits convencionales en español, sin atribución de IA. No se agregan tests nuevos del frontend; los existentes se mantienen en verde. Un cambio que dependa de un contrato nuevo de la API se coordina con `torquetrack-backend`.
