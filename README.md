# TorqueTrack Diesel — frontend (Vite + React + TypeScript)

Strangler-migration target for the existing Next.js app (frozen, untouched at
the repo root). See `docs/migration/` for the full migration design. This is
the Phase 1 scaffold: Vite, React, TypeScript, Tailwind CSS, and shadcn/ui are
wired in; `src/router.tsx` currently mounts a single placeholder route. Real
feature routes and API wiring land in Phase 8 (`src/features/*`).

## Local dev

```bash
pnpm install
pnpm dev
```

## Tests

```bash
pnpm test          # vitest run
pnpm exec vitest    # watch mode
```

## Type-check, lint, build

```bash
pnpm exec tsc -b
pnpm lint
pnpm build
```

## Adding shadcn/ui primitives

```bash
pnpm dlx shadcn@latest add <component>
```

`components.json` is already configured (aliases, Tailwind CSS variables).

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the Oxlint configuration

If you are developing a production application, we recommend enabling type-aware lint rules by installing `oxlint-tsgolint` and editing `.oxlintrc.json`:

```json
{
  "$schema": "./node_modules/oxlint/configuration_schema.json",
  "plugins": ["react", "typescript", "oxc"],
  "options": {
    "typeAware": true
  },
  "rules": {
    "react/rules-of-hooks": "error",
    "react/only-export-components": ["warn", { "allowConstantExport": true }]
  }
}
```

See the [Oxlint rules documentation](https://oxc.rs/docs/guide/usage/linter/rules) for the full list of rules and categories.
